# Fonts

Put the licensed webfont files here with exactly these names:

| File | Font |
|---|---|
| `SharpGrotesk-Book20.woff2` | Sharp Grotesk Book 20 (headings) |
| `NeueMontreal-Regular.woff2` | Neue Montreal Regular (body) |
| `NeueMontreal-Medium.woff2` | Neue Montreal Medium (buttons, emphasis) |
| `NeueMontreal-Italic.woff2` | Neue Montreal Italic (quotes) |

They are wired up in `src/styles/global.css`.
